SMS API: kendi yazılımından SMS gönder

WOLTSMS SMS API, sitenin, uygulamanın ya da iş yazılımının SMS'i elle değil otomatik göndermesini sağlar. Sipariş onayı, kargo bildirimi, randevu hatırlatma veya doğrulama kodu gibi mesajlar, olay gerçekleştiği anda kendiliğinden gider. Fiyat panelden gönderimle aynıdır: SMS başına ₺0,35.

API ile neler yapabilirsin?

  • Tek bir numaraya veya bir listeye toplu SMS gönderme
  • Gönderilen mesajların teslim durumunu sorgulama
  • Bakiye sorgulama
  • [DOLDUR: API'nin desteklediği diğer işlemler – ileri tarihli gönderim, webhook vb.]

Nerelerde kullanılır?

KullanımÖrnek mesaj
E-ticaret sipariş bildirimiSiparişin alındı. Sipariş no: 10482. Kargoya verildiğinde haber vereceğiz.
Kargo takibiSiparişin kargoya verildi. Takip no: 123456789.
Randevu hatırlatmaYarın 14:30'daki randevunu hatırlatırız. İptal için bu numarayı arayabilirsin.
Doğrulama kodu (OTP)Giriş kodun: 482913. Kodu kimseyle paylaşma.
Sistem uyarılarıSunucu disk doluluğu %90'ı geçti.

Entegrasyon adımları

  1. Üyelik aç ve bakiye yükle. Kayıt formu ile hesabını oluştur.
  2. API anahtarını oluştur. Panelde API bölümünden anahtarını al. Anahtarı kimseyle paylaşma ve kodunda açık metin olarak tutma.
  3. Dokümantasyonu incele. İstek adresi, parametreler ve hata kodları panelde yer alır.
  4. Test et, sonra canlıya al. Önce kendi numarana küçük bir gönderim yap, teslim raporunu kontrol et.

Örnek istek

Aşağıdaki örnek, isteğin genel yapısını gösterir. Gerçek adres ve parametre adları için panel dokümantasyonunu kullan.

  "message": "Siparişin alındı. Sipariş no: 10482"
}

Sık sorulan sorular

SMS API kullanmak için ek ücret var mı?

Hayır. API ile gönderilen her SMS, panelden gönderilenle aynı şekilde ₺0,35 olarak ücretlendirilir.

Hangi programlama dilleriyle çalışır?

API standart HTTP istekleriyle çalıştığı için PHP, Python, Node.js, C#, Java gibi HTTP isteği gönderebilen her dille kullanılabilir.

Bilgilendirme SMS'leri için İYS onayı gerekir mi?

Sipariş, kargo, randevu ve doğrulama kodu gibi bilgilendirme amaçlı mesajlar İYS onayı gerektirmez. Kampanya ve reklam içerikli mesajlar ise alıcının İYS'de kayıtlı onayını gerektirir. Ayrıntılar: İYS rehberi.
